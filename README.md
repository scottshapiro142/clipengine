# ClipEngine

ClipEngine is an AI-powered clipping application designed to take viral YouTube videos, automatically detect the best moments, and clip them into YouTube Shorts. It also generates and syncs captions automatically to maximize engagement.

## Features

* **YouTube Video Ingestion:** Input any public YouTube URL to download the video.
* **AI Moment Detection:** Analyzes the video to find the most engaging segments suitable for short-form content.
* **Auto-Clipping:** Crops the selected moments into vertical format (9:16) with a maximum duration of 60 seconds.
* **Auto-Captioning:** Generates accurate captions and syncs them perfectly with the audio.
* **Direct Export:** Ready-to-upload files for YouTube Shorts, TikTok, and Instagram Reels.

## Tech Stack

* **Frontend:** Next.js / React
* **Video Processing:** FFmpeg
* **Video Downloading:** yt-dlp
* **Caption Generation:** Whisper (or similar AI transcription model)
